## 왜 만들었나

- **예방의료의 구조적 한계** — 규칙적 운동, 정기검진, 프리미엄 앱에는 시간과 돈이 듭니다. 5년 주기 대장내시경은 반차와 마취라는 심리적 장벽이 높습니다.
- **낮은 장 건강 인식** — 면역세포의 약 70%가 장내에 있지만, '내 장 상태'를 아는 사람은 드뭅니다. 증상이 분명해질 때는 이미 질환이 진행된 뒤입니다.
- **지속성 낮은 식습관 앱** — 수치 비교와 텍스트만으로는 행동이 바뀌지 않습니다. 시각적 충격과 스토리텔링, 게임 요소가 필요합니다.
- **성장하는 제로슈가 시장** — 국내 제로 음료 시장은 2018년 약 0.2조 원에서 2023년 약 1.2조 원으로 커졌습니다. 건강해 보이는 선택이 장에 미치는 영향을 눈으로 확인할 수 있어야 합니다.

GutSense는 **손상은 즉각, 회복은 다음 끼니부터** 시각화해서 보상의 시간축을 뇌가 학습 가능한 범위로 압축합니다.

## 핵심 루프

한 끼를 고르면 새 상태가 나오는 6단계 폐쇄 루프입니다.

```
음식 선택 → 몸속 시뮬레이션 → 지표 반응 → AI 피드백(LLM) → 미션·회복 → 레벨업
```

### 4개 코어 지표와 점수 산식

SCFA를 출발점(독립변수)으로 나머지 세 지표가 인과적으로 이어집니다.

```
식단 → SCFA(단쇄지방산) → 장벽 투과성 → 전신 염증 → 도파민 감수성
```

| 지표 | 역할 | 시각 연출 |
| --- | --- | --- |
| SCFA (단쇄지방산) | 출발점 · 독립변수 | 발효 파티클이 장벽에 흡수되는 애니메이션 |
| 장벽 투과성 | Leaky gut 지표 | 융모 눌림 → 갈라짐 → 조각남 · 붉은 균열 |
| 전신 염증 | 확산 지표 | 장 → 혈류 → 뇌척수액 → 뇌, 원테이크 카메라 |
| 도파민 감수성 | 회로 상태 | 중뇌 발화 게이지, 파동 강도 변화 |

```
SCFA         = 100·f / (Km + f)
Permeability = 100 / (1 + e^(s(b−m)))
Inflammation = Barrier_term × LPS(1~3×) + HFD_direct   (≤ +15)
Dopamine     = floor + Δ / (1 + (i/h)^H)
```

- 도파미니(도파민 감수성 캐릭터)는 나쁜 음식에 크게 하락하고 좋은 음식에 완만히 회복합니다(비대칭).
- 아무리 나빠져도 완전히 죽지 않으며(하한선), 염증이 높으면 회복 상한이 눌립니다.
- 48시간 리셋 챌린지를 달성하면 균열 회복, 날씨 맑음, 도파미니 각성이 동시에 일어납니다.

> 점수 산식과 임계값은 설계 가정이며 임상적으로 검증되지 않았습니다.

## 화면 구성

**4개 메인 스테이지 + 히든 스테이지**로 이루어져 있고, 각 화면은 하나의 루프를 완성하는 마디입니다.

| 화면 | 설명 |
| --- | --- |
| 홈 · GUT WORLD | 진입 지점. 레벨, 오늘의 미션, 스트릭, Dr.장의 상태 평가 |
| 장맵 | 위·소장·대장 부위별 상태와 4개 코어 지표. 부위를 누르면 상세 분석과 Dr.장 가이드 |
| 식단 | AI 비전 스캔으로 하루 식단을 기록하고 "한 끼의 여정"을 시뮬레이션 |
| 타임비전 | 습관에 따라 달라지는 미래의 장 점막 내시경 화면 (Good ↔ Bad Path) |
| 미션 | 식단·운동·수면 미션, 스트릭, 레벨, 주간 랭킹, 48시간 리셋 챌린지 |
| 프로필 (레지던트 카드) | 의료 데이터 · 식단 AI 스캔 · 웨어러블 센서를 한 화면에 모은 데이터 허브 |
| 이상감지 | 장 상태 위험 알림과 행동 변화 유도 |
| Dr.장 랩실 (비밀진료실) | 장 상태 이미지와 LLM 의학 소견 |

앱에는 좋은 습관 / 나쁜 습관 두 가지 시연용 가상 페르소나가 있어서, 같은 하루에도 식습관에 따라 지표와 장 상태가 어떻게 갈라지는지 나란히 비교할 수 있습니다.

### 한 끼의 여정 (4막)

| 막 | 내용 |
| --- | --- |
| 1. 선택 | 사진을 찍는 순간 화면 톤이 바뀌고, 음식이 식도를 타고 내려갑니다 |
| 2. 침투 | 현미경 뷰에서 융모가 눌리고 갈라지고 조각납니다 |
| 3. 파급 | 카메라가 끊기지 않고 장 → 혈류 → 뇌척수액 → 뇌로 이어집니다 |
| 4. 피드백 | Dr.장이 "다음 끼니로 되돌릴 수 있어요"라며 회복 미션을 건넵니다 |

### Dr.장의 6단계 인과사슬

유해균 ↑ → SCFA ↓ → 투과성 ↑ → LPS 유입 → 염증 ↑ → 도파민 ↓. 각 단계를 누르면 Dr.장이 쉬운 말로 설명하고 지표가 바뀝니다.

## 기술 스택

| 영역 | 내용 |
| --- | --- |
| 프론트엔드 | 프레임워크 없는 Vanilla JS (빌드 단계 없음), 단일 `index.html` + `js/` 모듈 |
| 3D · 애니메이션 | Three.js (3D 장 모델, 장-뇌 축, 장 속 시뮬레이션), GSAP, 자체 구현 이펙트 |
| AI 캐릭터 | SVG 캐릭터 Dr.장 + LLM 연동 말풍선 |
| LLM | GLM-4.5-flash / GPT-4o-mini 멀티 모델, 실패 시 기본 멘트(fallback)로 자동 전환 |
| 모바일 | Capacitor 7 하이브리드 (`com.gutsense.app`), PWA 서비스워커 |
| 배포 | Cloudflare Pages (정적) + Cloudflare Worker (LLM 프록시) |

### 배포 구조

```
브라우저 앱 (Pages) → LLM 프록시 Worker → LLM API
```

- API 키는 **Worker 시크릿에만** 존재하고 브라우저에 노출되지 않습니다.
- Worker는 허용된 Origin에서 온 요청만 받습니다 (`deploy/wrangler.toml`의 `ALLOWED_ORIGINS`).
- LLM 호출이 실패해도 앱은 기본 멘트로 계속 동작합니다.

## 기대효과

1. **접근성** — 스마트폰 하나로 장 상태를 확인합니다. 시간·비용·정보 격차를 앱 하나로 우회합니다.
2. **행동변화** — 손상은 즉각, 회복은 다음 끼니부터 보여줍니다. 결과가 바로 보이니 다음 선택이 달라집니다.
3. **예방 · 손해율** — 5~10년 검진 주기 사이의 '블랙박스 구간'을 매일의 시각 피드백으로 채워 만성질환 발병률 감소를 목표로 합니다.
4. **데이터 · 에코시스템** — 장 건강 지표를 실제 행동 변화·결과 데이터로 축적해 장 건강 연동형 스마트 리워드와 행동 데이터 기반 차별화 보험 상품의 기반을 제공합니다.

### 10년 후를 전제로 한 설계

웨어러블 기기로 장의 실시간 상태를 일상에서 확인하는 시대(2036년)를 전제로 설계했습니다. 현재는 이 원천 데이터를 구하기 어려우므로 mock 데이터로 시뮬레이션합니다. 의료 데이터, 식단 AI 스캔, 웨어러블 센서가 연동되면 자연스럽게 확장되는 구조입니다.

## 알려진 한계

- **로그인은 시뮬레이션**입니다. 카카오 / 삼성생명 로그인은 실제 서버와 통신하지 않습니다.
- **예측 이미지는 사전 준비된 자산**입니다. 실제 생성형 모델(diffusion) 연동에는 API 키와 백엔드가 필요합니다.
- 의료 데이터, 식단 스캔, 웨어러블 센서는 **mock 데이터**입니다.
- 지표 수치와 산식은 설계 가정이며 임상적으로 검증되지 않았습니다.
